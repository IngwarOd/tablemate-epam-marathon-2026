# Tablemate — спільна вечеря без хаосу

Самостійний вебпроєкт для EPAM IT Marathon 2026. Організатор створює стіл, запрошує гостей, бачить їхні кошики та надсилає ресторану одне консолідоване передзамовлення. Окремий приватний кухонний талон показує підтверджене замовлення працівнику ресторану. **«Баланс столу»** показує використання бюджету, підказує дешевшу заміну ще не підтвердженої страви й відмічає збіги з указаними гостями алергенами. **«Розділити рахунок»** розраховує внесок кожного за власним кошиком із чайовими 0–15% та розподіляє округлення так, щоб сума точно збігалася. Підказки щодо алергенів не замінюють перевірку складу в ресторані.

## Запуск

Потрібен Node.js 22+. Сервер не потребує npm-залежностей або зовнішнього API. Фотографії та шрифти завантажуються з Unsplash і Google Fonts; якщо вони недоступні, залишаються емодзі та системні шрифти.

```powershell
cd D:\epam_project\tablemate
npm start
```

Відкрийте <http://localhost:3000>. Кнопка **«Подивитися живе демо»** створює реальний демо-стіл із двома гостями й різними станами кошиків. Для перевірки запрошення скопіюйте посилання з панелі організатора й відкрийте його в іншому профілі браузера або приватному вікні. Кнопка **«Кухонний талон»** показує окремий екран для працівника ресторану; **«Скопіювати талон»** дає приватне посилання тільки для читання. Після відправлення замовлення на кухонному екрані натисніть **«Оновити талон»**.

```powershell
npm test
```

## Як це пов'язано із завданням марафону

Фінальне повідомлення каналу від 30.10.2026 визначає рівень 3 як **розгорнутий застосунок із запропонованою або власною додатковою функціональністю**. Цей проєкт реалізує ресторанний сценарій групового передзамовлення та власну функцію «Баланс столу». Він є окремою реалізацією, а не форком наданого Angular/.NET застосунку.

| Сценарій | Реалізація |
| --- | --- |
| Перегляд учасників і суми | Панель організатора, `GET /api/groups/:id/sessions` |
| Власний кошик організатора | Сесія типу `Owner` |
| Запрошення гостей | Приватне посилання з кодом запрошення |
| Консолідація лише підтверджених кошиків | `POST /api/groups/:id/submit` |
| Видалення гостя і перерахунок суми | `DELETE /api/groups/:id/sessions/:sessionId` |
| Перегляд замовлення кухнею | Приватний талон, `GET /api/groups/:id/kitchen` |
| Додаткові функції | Бюджет, порада щодо заміни, перевірка вказаних алергенів, персональний поділ рахунку з чайовими |

**Текст для поля 4/4 анкети:** «Реалізовано власний модуль “Баланс столу”: він у реальному часі порівнює кошики учасників зі спільним бюджетом, пропонує дешевшу безпечну заміну страви та попереджає про вказані алергени. Додано інтерактивний поділ рахунку: організатор бачить суму кожного кошика й частку чайових; округлення розподіляється точно до гривні. Є окремий кухонний талон із доступом лише на читання.»

Після підтвердження група має статус `Submitted`, а замовлення — `SubmittedByCustomer`. Повторне підтвердження повертає 409. Порожня група містить тільки організатора, загальна сума — 0. Сторонній користувач і гість не отримують панель організатора. Видалення учасника іншої групи повертає 400, відсутнього — 404.

## Архітектура та дані

- Node.js HTTP API і статичний інтерфейс на HTML/CSS/JavaScript. npm-пакети й зовнішній backend не потрібні.
- Для організатора, кожного гостя й кухонного талона видається окремий випадковий токен. На сервері зберігається лише SHA-256 хеш токена. Посилання на запрошення та кухонний талон не дають прав організатора. Ключ кухні передається у фрагменті URL і після відкриття прибирається з адресного рядка.
- Час зустрічі зберігається як абсолютний ISO-час разом зі зсувом UTC на дату зустрічі; усі учасники та кухня бачать той самий запланований час, навіть якщо їхні браузери працюють в інших часових поясах.
- Групи зберігаються у `data/store.json` (шлях можна змінити через `DATA_FILE`). Папка `data/` ігнорується Git.
- `PORT` задає порт, за замовчуванням 3000. Публічна версія використовує Cloudflare Worker і R2; її вихідний код та тести знаходяться у `../sites/tablemate/`. Кожна група зберігається окремим об’єктом, а умовні записи за ETag захищають від тихого перезапису одночасних змін.

Контейнер для хостингу з постійним диском:

```bash
docker build -t tablemate .
docker run -p 3000:3000 -v tablemate-data:/data tablemate
```

Ці команди наведені як інструкція для розгортання; в цьому середовищі Docker-образ не збирався.

Публічний сайт працює через HTTPS і зберігає групи у R2. Резервне копіювання та обмеження частоти запитів не налаштовані; не вводьте чутливі персональні дані. Локальна файлова реалізація розрахована на один процес.

## Перевірка вручну

1. Створіть стіл або завантажте демо.
2. Скопіюйте запрошення, відкрийте його в приватному вікні, приєднайтеся як гість.
3. Додайте страви, перевірте повідомлення про алерген, підтвердіть кошик.
4. У вікні організатора оновіть сторінку, змініть бюджет, видаліть одного гостя або підтвердіть групове замовлення.
5. Відкрийте кухонний талон за окремим посиланням і перевірте, що в ньому є тільки страви з підтверджених кошиків.
